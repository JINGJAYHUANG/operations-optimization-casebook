# Limitations

- Public instances are synthetic and intentionally small.
- Continuous product mix assumes linear economics and constraints.
- Transportation is single-period and balanced.
- Assignment is one-to-one.
- Facility location uses single-source customer allocation.
- Workforce scheduling aggregates skills and preferences.
- Newsvendor uses a supplied discrete distribution.
- Project crashing uses deterministic durations and no resource leveling.
- Vehicle routing uses Euclidean distance and omits traffic and time windows.
- Robust choice depends on modeled scenarios and weights.
- Capital budgeting uses additive value except for explicit dependencies.
- Hash chains detect mutation inside an evidence bundle but do not provide signer identity.
- Passing the suite does not certify a real model, data source, solver, or implementation.
